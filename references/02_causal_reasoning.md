# Reference Primer — Causal Reasoning

## Central distinction

CDCO requires causal links, not associations.

A bridge should have:
1. a source intervention,
2. a state change,
3. a mechanism,
4. a receiving effect,
5. a counterfactual.

## Causal mediation

A common CDCO bridge has mediated form:

`A -> M -> B`

where:
- A is an action,
- M is a state change,
- B is the downstream condition or affordance.

The mediator is often the true object of planning.

Example:
`pilot -> measured evidence -> lower uncertainty in financing analysis`

## Counterfactual reasoning

Ask:
> If the source action had not happened, would the target dimension face a different decision-relevant condition?

This does not prove causality in a scientific sense, but it is an essential planning discipline.

## Necessary vs. sufficient conditions

A bridge may create:
- a **necessary** condition: B cannot proceed without X;
- a **sufficient** condition: X alone is enough for B;
- an **enabling** condition: X makes B feasible but other conditions remain;
- a **facilitating** condition: X improves probability/cost/timing without being required.

Most CDCO bridges are enabling or facilitating, not sufficient.

## Confounding warning

If A and B both respond to an outside factor C, do not assume A causes B.

Planning consequence:
Look for the mechanism by which A changes B's state, not merely common timing.

## Mechanism quality

Strong mechanism:
- concrete,
- observable,
- short,
- few assumptions.

Weak mechanism:
- abstract,
- depends on several hoped-for responses,
- cannot be observed.

## Agent checklist

- What exactly changes?
- Who/what encounters the change?
- Through what mechanism?
- Is another variable actually responsible?
- Is the state necessary, sufficient, enabling, or facilitating?
- What evidence would weaken this bridge?

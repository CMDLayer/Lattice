# Reference Primer — Strategy and Indirect Leverage

## Direct vs. indirect action

Direct:
Act on the target objective itself.

Indirect:
Change a condition that changes the target's environment.

CDCO systematically searches for legitimate indirect leverage.

## Shaping conditions

A plan can create:
- capability,
- evidence,
- access,
- timing,
- resources,
- constraints,
- or optionality
that changes later strategic choices.

## Complementarity

Two assets may be much more valuable together than separately.

CDCO question:
Can one dimension create the complement another dimension lacks?

## Sequencing

Order matters when early states change the quality of later decisions.

Common strong sequence:
`learn -> create evidence -> create access -> scale`

But the skill should not hard-code this; it must derive sequencing from conditions.

## Position

A plan may improve relative position without directly achieving the terminal objective.

Examples:
- reduce dependency,
- create alternatives,
- improve bargaining position,
- lower switching cost,
- increase credible options.

## Agent questions

- What condition, if created elsewhere, would make the direct path easier?
- What complement is missing?
- Which state changes bargaining or choice quality?
- What sequence reduces irreversible risk?

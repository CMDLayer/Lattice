# Reference Primer — Uncertainty, Information, and Optionality

## CDCO does not require prediction

The framework can create advantage by changing the available choices even when the future is uncertain.

## Value of information

Some actions are worthwhile mainly because they reduce uncertainty.

Pattern:
`learning action -> information state -> better downstream decision`

This can be a legitimate bridge even if no immediate operational output is produced.

## Reversibility

Prefer reversible early actions when:
- uncertainty is high,
- irreversible commitments are expensive,
- or the architecture depends on weak bridges.

## Option value

A state can be valuable because it gives the user the right—but not obligation—to take a future action.

Examples:
- prequalified vendor,
- prototype,
- signed but non-exclusive partnership option,
- reserve capacity,
- reusable evidence,
- modular architecture.

## Calibration

Represent bridge confidence separately from importance.

A bridge can be:
- very important but uncertain,
- reliable but low impact.

Do not collapse those dimensions.

## Agent questions

- What do we need to learn before committing?
- Which actions create information?
- Which states create multiple future moves?
- What expires?
- Which commitments are irreversible?

# Worked Example 4 — Personal Project Portfolio

## Scenario

A person wants to:
- build expertise in a new field,
- develop a public body of work,
- and improve future career options,
while working limited hours each week.

## Dimensions

### D1 — Learning
Local objective: acquire durable competence.

Plan:
- structured curriculum,
- deliberate practice,
- small projects,
- periodic assessment.

### D2 — Public Work
Local objective: create useful artifacts that demonstrate thinking.

Plan:
- publish notes,
- build small tools or analyses,
- write case studies,
- maintain a coherent portfolio.

### D3 — Career Exploration
Local objective: learn which roles and organizations fit.

Plan:
- map role families,
- speak with practitioners,
- test small collaborations,
- track fit criteria.

## Bridges

Learning → Public Work:
practice projects become publishable artifacts.

Public Work → Career Exploration:
portfolio creates a concrete basis for conversations and feedback.

Career Exploration → Learning:
practitioner conversations reveal which skills are actually valued.

Career Exploration → Public Work:
real problems discovered in conversations generate better project prompts.

## Architecture — Learning Flywheel

```text
Learning
   │ produces artifacts
   ▼
Public Work
   │ creates concrete conversation surface
   ▼
Career Exploration
   │ reveals real capability gaps
   └───────────────> Learning
```

The plans are independently useful, but their consequences reinforce one another.
